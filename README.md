# 님 게임 PWA

## 구성
- `index.html`: 게임 화면과 로직
- `manifest.json`: 홈 화면 설치 설정
- `sw.js`: 오프라인 캐시
- `icon.svg`: 앱 아이콘

## 휴대폰 설치 방법
PWA는 HTTPS 웹 주소에서 열어야 설치할 수 있습니다.

1. GitHub에서 새 저장소 `nim-game`을 만듭니다.
2. 이 폴더의 파일 4개를 저장소 최상위에 업로드합니다.
3. 저장소의 **Settings → Pages**에서 `Deploy from a branch`, `main`, `/(root)`를 선택하고 저장합니다.
4. 게시된 HTTPS 주소를 안드로이드 Chrome에서 엽니다.
5. Chrome 메뉴 `⋮` → `앱 설치` 또는 `홈 화면에 추가`를 누릅니다.

## 게임
- 무더기 수 1~10개, 각 무더기 0~999개 설정
- 하: 무작위 수
- 중: XOR로 이기는 수가 있으면 우선 선택, 아니면 무작위
- 상: 일반 님 게임의 XOR 최적 전략
- 마지막 돌을 가져가는 사람이 승리

주의: 상 난이도는 컴퓨터 차례의 최적 수를 선택하지만, 시작 위치가 이미 불리하면 반드시 이기는 것은 아닙니다.
